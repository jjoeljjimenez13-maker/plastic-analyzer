# Plastic Analyzer

Interactive incremental elastic-plastic frame analyzer. Built with React + Vite + Tailwind CSS.

## Live demo

Once GitHub Pages is enabled on this repo, the app is served at:
`https://USERNAME.github.io/plastic-analyzer/`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The output goes to `dist/`. A GitHub Actions workflow at `.github/workflows/deploy.yml` builds and deploys this on every push to `main`.
